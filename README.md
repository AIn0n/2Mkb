# MX MIDI KEYBOARD

This is project is highly inspired by MIDI88, shout out to the author!

The main problem with it is a fact, that is full dimension keyboard and I don't have the 
space or switches to handle it. So I decided to develop my own, parametrisable model, which
could handle as many keys as I want. Currently, it's designed to handle 38 keys - single pack
of gateron MX switches, minus two for octave up and down.

## Frontend

Developed using streamlit. The main idea behind it is to make model accessible for people without any
kind of programming experience. Running the code using some sort of claude is probably possible,
but way easier it will be for end user, to just go to the website, insert the dimensions, see
the model and download everything zipped.
